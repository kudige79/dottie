# Dottie update compatibility

Dottie is freeware, not open source. Its source code is private.

Download Dottie only from the official Game Pac website:

https://game-pac.com/#dottie

This public repository exists solely so older installed copies can move to the
current automatic-update service. It contains no source code and no installer.
Its frozen `appcast.xml` release asset is a permanent compatibility endpoint and
must not be replaced or removed.
